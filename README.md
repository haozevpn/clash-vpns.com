## 🎨 视觉设计系统

### 配色方案
```css
--cream: #F7F4EF          /* 背景色 - 温暖的奶油色 */
--surface: #FBF9F5        /* 卡片背景 - 更浅的表面色 */
--white: #FFFFFF          /* 纯白 - 用于高对比度卡片 */
--border: #E7E1D7         /* 边框 - 柔和的分隔 */
--ink: #1F2421            /* 正文 - 炭黑色 */
--muted: #5C635D          /* 辅助文字 - 柔和灰 */
--terracotta: #C4612F     /* 主色 - 陶土色（品牌色）*/
--terracotta-hover: #A94E22  /* 主色悬停态 */
--tint: #F2E3D6           /* 浅色调 - 标签背景 */
```

### 字体系统
- **标题：** Fraunces（衬线字体，权威感）
- **正文：** Inter（无衬线，现代易读）
- **字重：** 300（正文）、400（常规）、500（中等）、600（半粗）

### 圆角规范
- 小元素（标签）：`999px`（全圆角）
- 卡片/按钮：`12px`
- 图标容器：`8-16px`

### 间距系统
- 容器最大宽度：`1200px`
- 栅格间距：`2rem` (32px)
- 卡片内边距：`2rem` (32px)
- 元素间距：`1rem` / `1.5rem` / `2rem`

## 📊 内容结构框架

### 测评文章标准结构（11个必含章节）

1. **快速结论**（200字）
   - 一句话总结 + 核心数据 + 适合人群

2. **基本信息表格**
   - 运营时间、价格、节点、支付方式

3. **速度测试**（必须标注测试环境）
   - 多节点测试数据表格
   - 晚高峰/非高峰对比

4. **流媒体解锁测试**（标注测试时间）
   - Netflix/Disney+/HBO等
   - 风险提示：会失效

5. **AI工具适配**
   - ChatGPT/Claude/Gemini

6. **套餐与价格**
   - 价格表格 + 性价比分析

7. **优缺点对比**
   - 双栏布局，各3-5条

8. **稳定性评估**
   - 可用率、晚高峰表现、客服

9. **风险提示**（必含）
   - 跑路风险、建议月付

10. **适合人群**
    - 推荐使用 / 不推荐使用

11. **测试方法说明**（页尾）
    - 测试环境、工具、评分标准

## 🚀 快速启动指南

### 第一步：选择技术栈

**推荐新手：** Next.js + MDX
```bash
npx create-next-app@latest airport-reviews --typescript --tailwind --app
cd airport-reviews
npm install contentlayer next-contentlayer
npm run dev
```

**追求性能：** Astro
```bash
npm create astro@latest airport-reviews
cd airport-reviews
npm run dev
```

**极简方案：** Hugo
```bash
brew install hugo
hugo new site airport-reviews
hugo server
```

### 第二步：复制设计系统

1. 将 `index.html` 的 CSS 部分提取为 Tailwind 配置
2. 或直接使用提供的 CSS 变量系统
3. 复制组件结构到你的框架中

### 第三步：创建内容模板

1. 使用 `TECH-IMPLEMENTATION.md` 中的 YAML 结构
2. 创建第一篇测评文章
3. 填入真实测试数据

### 第四步：SEO 配置

1. 设置 Metadata（参考技术文档）
2. 生成 Sitemap
3. 添加结构化数据（JSON-LD）
4. 提交 Google Search Console

### 第五步：部署

**Vercel（推荐）：**
```bash
npm install -g vercel
vercel
```

**Cloudflare Pages：**
```bash
npm run build
wrangler pages publish ./out
```

## ⚠️ 重要提醒

### 内容创作注意事项

1. **绝不编造数据**
   - 所有速度、价格、解锁数据必须真实测试
   - 无法测试的项目标注"未测试"，不要猜测

2. **时效性标注**
   - 每条数据都标注测试时间
   - 明确说明"数据会变化"

3. **风险披露**
   - 多处提示机场跑路风险
   - 建议月付，不推荐年付
   - 建议备用机场

4. **合规表述**
   - 避免："翻墙"、"突破封锁"
   - 使用："科学上网"、"代理服务"

5. **联盟链接**
   - 使用 `rel="nofollow"`
   - 声明包含推广链接
   - 不让利益影响客观性

### 法律合规

- ✅ 声明"仅提供技术测评，不提供代理服务"
- ✅ 声明"使用需遵守当地法律法规"
- ✅ 声明"用户自行承担使用风险"
- ❌ 不承诺"永久稳定"
- ❌ 不诱导大额充值
