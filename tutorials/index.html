新手使用教程

从零开始，快速掌握机场使用方法

📚 什么是机场？

机场是提供代理节点服务的平台，通过订阅链接为用户提供多个节点。相比传统VPN，机场具有以下特点：

  • 节点多样化：提供多国家/地区节点，可自由切换
  • 速度更快：采用专线、IPLC等优质线路，延迟低速度快
  • 按流量计费：灵活套餐，适合不同使用场景
  • 协议先进：支持Shadowsocks、VMess、Trojan等新协议

机场和VPN的区别

  • VPN：点对点加密隧道，通常单一服务器，适合企业远程办公
  • 机场：代理节点集合，多节点可选，适合流媒体、AI工具等场景
💡 提示：机场使用需配合客户端软件（Clash、Shadowrocket等），通过订阅链接导入节点。

⚡ Clash Verge 使用教程

适用平台：Windows / macOS / Linux

1. 下载安装

  1. 访问 Clash Verge GitHub 下载对应系统版本
  2. Windows下载 .exe 安装包，macOS下载 .dmg 文件
  3. 安装并打开软件

2. 导入订阅链接

  1. 从机场网站复制订阅链接（Clash订阅）
  2. 打开Clash Verge，点击左侧「订阅」
  3. 点击右上角「+」按钮，选择「从链接导入」
  4. 粘贴订阅链接，点击「确定」
  5. 等待节点更新完成

3. 选择节点并启动

  1. 点击「代理」标签页
  2. 选择「节点选择」组，点击想用的节点
  3. 回到主界面，打开「系统代理」开关
  4. 选择「规则模式」（推荐）或「全局模式」
💡 模式说明：
  • 规则模式：国内网站直连，国外网站走代理（推荐日常使用）
  • 全局模式：所有流量都走代理
  • 直连模式：不使用代理

🚀 Shadowrocket 使用教程

适用平台：iOS (iPhone / iPad)

1. 下载安装

  • 在美区/港区App Store搜索「Shadowrocket」购买下载（$2.99）
  • 或使用共享美区账号下载（已购买版）

2. 导入订阅

  1. 从机场网站复制订阅链接（通用订阅或Shadowrocket订阅）
  2. 打开Shadowrocket，点击右上角「+」
  3. 选择「类型」→「Subscribe」
  4. 在「URL」栏粘贴订阅链接
  5. 点击右上角「完成」
  6. 点击订阅右侧箭头进入，刷新获取节点

3. 连接节点

  1. 回到首页，选择一个延迟低的节点
  2. 点击顶部开关启动连接
  3. 首次使用需在系统弹窗中点击「允许」
  4. 状态栏出现VPN图标即为连接成功
⚠️ 注意：订阅链接不要分享给他人，避免流量被盗用。定期更新订阅以获取最新节点。

📦 sing-box 使用教程

适用平台：Android / iOS / Windows / macOS / Linux

1. 下载客户端

  • Android：下载 SFA (Sing-Box for Android)
  • iOS：App Store搜索「sing-box」
  • 桌面端：访问 GitHub 下载对应版本

2. 导入配置

  1. 从机场获取sing-box订阅链接
  2. 打开客户端，点击「+」或「添加配置」
  3. 选择「从URL导入」
  4. 粘贴订阅链接，点击「导入」

3. 启动连接

  1. 选择一个配置文件
  2. 点击连接按钮
  3. 允许VPN权限

优势：sing-box是新一代代理工具，性能优秀，支持多种协议，配置灵活。

🔗 订阅链接怎么用？

获取订阅链接

  1. 登录机场网站
  2. 进入「用户中心」或「我的订阅」
  3. 找到「订阅链接」区域
  4. 根据客户端类型选择对应链接：
    • Clash 订阅
    • 通用订阅（Shadowrocket、V2rayN等）
    • sing-box 订阅
  5. 点击「复制」按钮

导入到客户端

各客户端导入方法见上方对应教程。通常步骤为：

  1. 打开客户端
  2. 找到「订阅」或「配置」功能
  3. 选择「从URL导入」
  4. 粘贴订阅链接
  5. 更新/下载节点
⚠️ 安全提示：
  • 订阅链接等同于账号密码，不要泄露给他人
  • 不要在不可信的第三方网站使用订阅链接
  • 如订阅链接泄露，立即在机场后台重置

📖 专业术语解释

节点延迟是什么意思？

延迟（Ping）是指数据从你的设备到代理节点服务器的往返时间，单位为毫秒(ms)。

  • <50ms：优秀，几乎无感知延迟
  • 50-150ms：良好，日常使用流畅
  • 150-300ms：一般，网页浏览可接受
  • >300ms：较差，可能出现卡顿

影响因素：物理距离、线路质量、网络拥堵程度。

流量倍率是什么？

倍率是指使用节点时的流量扣费系数：

  • 1倍：使用1GB流量，扣除1GB（普通节点）
  • 0.5倍：使用1GB流量，仅扣0.5GB（低倍率优惠节点）
  • 2倍：使用1GB流量，扣除2GB（高速专线节点）

建议：日常浏览用低倍率节点省流量，下载/流媒体用高倍率专线节点保速度。

IPLC / IEPL 是什么？

  • IPLC：国际专线，点对点物理连接，不过墙不受干扰，高峰期稳定
  • IEPL：国际以太网专线，类似IPLC，更灵活
  • 优势：延迟低、速度快、稳定性高，适合对网络质量要求高的用户

流媒体解锁是什么？

部分节点使用原生IP（当地运营商IP），可以访问该地区的流媒体服务：

  • Netflix：美区、日区、新加坡等地区内容库
  • Disney+：迪士尼流媒体服务
  • YouTube Premium：部分地区会员功能
  • TikTok：国际版抖音访问

❓ 常见问题解决

1. 节点连不上 / 延迟超时

  • 检查本地网络是否正常
  • 更新订阅获取最新节点
  • 切换其他节点尝试
  • 检查客户端是否是最新版本

2. 流量用完怎么办？

  • 在机场网站购买流量包
  • 升级到更大流量套餐
  • 续费下个月套餐（月付用户）

3. 速度很慢怎么办？

  • 选择延迟更低的节点
  • 避开高峰期（晚上8-11点）
  • 使用专线节点（IPLC/IEPL）
  • 联系机场客服反馈节点问题

4. 订阅更新失败

  • 检查订阅链接是否正确
  • 尝试手动删除旧订阅重新添加
  • 检查机场网站是否可以正常访问
  • 确认套餐是否已过期
