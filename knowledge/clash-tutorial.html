Clash完全使用教程：从安装到进阶配置

Clash是目前最流行、功能最强大的代理工具之一。本文将从零开始，详细讲解Clash的安装、订阅导入、规则配置、节点测速等核心功能，帮助新手快速上手，同时覆盖进阶配置技巧，让老手也能深度优化使用体验。

一、Clash是什么

Clash是一款基于Go语言开发的跨平台代理工具，支持Shadowsocks、VMess、Trojan等多种代理协议。它的核心优势在于强大的规则分流功能，可以实现国内直连、国外代理的智能切换，大幅提升网络访问效率。

Clash的主要特点

  • 规则分流：根据域名、IP自动选择直连或代理
  • 多协议支持：兼容SS、SSR、VMess、Trojan、VLESS等
  • 图形界面：提供友好的GUI，配置简单直观
  • 节点测速：一键测试所有节点延迟和速度
  • 订阅管理：支持机场订阅链接，自动更新节点

二、Clash客户端下载与安装

Windows系统：Clash for Windows

Clash for Windows（简称CFW）是Windows平台最流行的Clash客户端。

  1. 下载客户端：访问GitHub项目页面（Fndroid/clash_for_windows_pkg）下载最新版本
  2. 解压运行：下载后解压到任意文件夹，双击Clash for Windows.exe启动
  3. 首次启动：会自动创建配置文件夹，位于用户目录\.config\clash
💡 提示：

部分杀毒软件可能误报，需要添加信任。GitHub下载速度慢可以使用镜像站或从机场官网下载。

macOS系统：ClashX Pro

Mac用户推荐使用ClashX Pro，它是Clash的原生macOS客户端。

  1. 从GitHub下载ClashX Pro（yichengchen/clashX）
  2. 拖入Applications文件夹安装
  3. 首次打开需要在"系统偏好设置→安全性"中允许运行
  4. 授予网络权限，允许拦截网络流量

Android系统：Clash for Android

Android用户使用Clash for Android（Kr328/ClashForAndroid）。

  1. 从GitHub或Google Play下载APK安装
  2. 安装后授予VPN权限
  3. 部分国产ROM可能需要关闭省电模式，避免后台被杀

iOS系统：Shadowrocket/Stash

iOS由于系统限制，没有官方Clash客户端，推荐使用Shadowrocket（$2.99）或Stash（$3.99），都支持Clash配置文件。

三、导入机场订阅

订阅链接是机场提供的节点配置URL，通过订阅可以一键导入所有节点，并自动更新。

获取订阅链接

  1. 登录机场官网，进入"我的订阅"或"仪表盘"页面
  2. 找到"Clash订阅"或"通用订阅"，复制链接
  3. 部分机场区分"Clash"和"Clash Premium"订阅，选择对应版本

Clash for Windows导入订阅

  1. 打开Clash for Windows，点击左侧Profiles（配置）
  2. 在顶部输入框粘贴订阅链接
  3. 点击Download（下载），等待配置文件下载完成
  4. 下载成功后，配置文件会出现在列表中，点击配置文件名称激活
  5. 返回General（常规）页面，打开System Proxy（系统代理）开关
⚠️ 注意：

订阅链接类似密码，不要泄露给他人。如果订阅链接失效，可以在机场官网重置。

订阅更新

机场会定期添加或删除节点，建议每周更新一次订阅：

  • 在Profiles页面，点击配置文件右侧的刷新图标
  • 或者设置自动更新：右键配置文件→Update Interval（更新间隔）→选择24小时

四、节点选择与测速

手动选择节点

  1. 点击Proxies（代理）页面
  2. 在GLOBAL（全局）或Proxy（代理）分组中选择节点
  3. 点击节点名称即可切换

节点测速

Clash支持一键测试所有节点的延迟：

  1. 在Proxies页面，点击速度测试图标（闪电图标）
  2. Clash会依次测试所有节点到目标服务器的延迟
  3. 测速结果显示在节点名称后方（单位：毫秒）
  4. 延迟越低速度越快，一般<100ms为优秀，100-300ms为良好
💡 测速技巧：

Clash默认测速目标是http://www.gstatic.com/generate_204，测的是延迟而非带宽。真实速度还需考虑带宽、丢包率等因素。

自动选择最快节点

部分机场订阅包含Auto（自动选择）节点组，Clash会根据测速结果自动选择延迟最低的节点。使用方法：

  1. 先执行一次测速
  2. 在代理分组中选择Auto或♻️ 自动选择
  3. Clash会自动切换到延迟最低的可用节点

五、代理模式详解

Clash提供三种代理模式，在General页面切换：

1. Rule（规则模式）⭐ 推荐

  • 工作原理：根据配置文件中的规则，自动判断流量是直连还是代理
  • 适用场景：日常使用，国内网站直连，国外网站代理
  • 优势：智能分流，节省流量，速度快

2. Global（全局模式）

  • 工作原理：所有流量都走代理
  • 适用场景：需要全局代理的特殊情况（如游戏加速）
  • 劣势：国内网站也走代理，速度慢且浪费流量

3. Direct（直连模式）

  • 工作原理：所有流量都不经过代理
  • 适用场景：暂时不需要代理时关闭

六、规则分流详解

规则分流是Clash的核心功能，通过规则自动识别流量并选择路由。

常见规则类型

  • DOMAIN：精确匹配域名（如google.com）
  • DOMAIN-SUFFIX：匹配域名后缀（如google.com匹配www.google.com、mail.google.com）
  • DOMAIN-KEYWORD：匹配域名关键词（如google匹配所有包含google的域名）
  • IP-CIDR：匹配IP段（如1.1.1.1/32）
  • GEOIP：根据IP地理位置匹配（如GEOIP,CN,DIRECT表示中国IP直连）

规则示例

# 谷歌服务走代理
DOMAIN-SUFFIX,google.com,Proxy
DOMAIN-SUFFIX,googleapis.com,Proxy

# 国内网站直连
DOMAIN-SUFFIX,baidu.com,DIRECT
DOMAIN-SUFFIX,qq.com,DIRECT

# 中国IP直连
GEOIP,CN,DIRECT

# 其他流量走代理
MATCH,Proxy

使用规则集

手动编写规则太繁琐，推荐使用社区维护的规则集：

  • ACL4SSR：最流行的规则集，分类详细
  • Loyalsoldier：简洁高效的规则集
  • DivineEngine：针对流媒体优化的规则集

在机场订阅时，大部分已内置规则集，无需手动配置。

七、进阶功能

TUN模式（Clash Premium）

TUN模式可以代理所有流量，包括不支持系统代理的应用（如游戏、终端命令）。

  1. 确保使用Clash Premium版本
  2. 在General页面打开TUN Mode
  3. 首次启动需要管理员权限安装虚拟网卡
⚠️ 注意：

TUN模式下所有流量都会经过Clash，可能与某些安全软件冲突。不使用时建议关闭。

脚本功能（Script）

Clash支持JavaScript脚本，可以实现更复杂的逻辑判断，如：

  • 根据时间段切换节点
  • 根据网速动态切换线路
  • 自定义负载均衡策略

日志查看

遇到问题时，可以查看日志排查：

  1. 点击Logs（日志）页面
  2. 日志会实时显示连接信息、规则匹配情况
  3. 通过日志可以判断某个域名走了直连还是代理

八、常见问题解决

Q1: 开启代理后无法上网

  • 检查系统代理：确保System Proxy已打开
  • 检查端口占用：Clash默认端口7890，确保没有被其他程序占用
  • 切换节点：当前节点可能失效，切换到其他节点
  • 更新订阅：节点可能已过期，尝试更新订阅

Q2: 部分网站无法访问

  • 检查规则：可能被规则判定为直连，在Logs查看匹配结果
  • 切换为全局模式：临时使用Global模式测试
  • 更换节点：某些节点可能被特定网站屏蔽

Q3: 速度很慢

  • 执行测速：选择延迟最低的节点
  • 检查本地网络：确保本地网络正常
  • 避开高峰期：晚上8-11点是使用高峰，速度会下降
  • 更换机场：可能是机场超售，考虑更换更稳定的机场

Q4: 规则不生效

  • 确认规则模式：必须在Rule模式下规则才会生效
  • 检查规则顺序：规则从上到下匹配，优先匹配的规则会被执行
  • 清除DNS缓存：ipconfig /flushdns（Windows）或重启Clash

九、总结

Clash作为目前最强大的代理工具，功能丰富但配置灵活。对于新手，建议：

  • 使用机场提供的托管配置，开箱即用
  • 选择Rule（规则）模式，日常使用最便捷
  • 定期测速，选择延迟低的节点
  • 定期更新订阅，保持节点最新

对于进阶用户，可以：

  • 自定义规则，精准控制分流逻辑
  • 使用TUN模式，代理全部流量
  • 通过Script实现自动化策略
  • 结合多个机场订阅，实现负载均衡
